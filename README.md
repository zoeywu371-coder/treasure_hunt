# 🏴‍☠️ Treasure Hunt

Welcome to **Treasure Hunt**, an interactive adventure game built in Python! Navigate through the map grid, avoid obstacles, and reach the hidden treasure.

---

## How to Play

### Map Legend
The game map is displayed in your terminal using the following grid characters:

* `x` — **Wall / Obstacle:** Impassable terrain that blocks your path.
* `.` — **Empty Space:** Walkable paths you can move across.
* `T` — **Treasure:** Your target! Reach this space to win the game.

### Game Controls
1. Launch the game by clicking and downloading the "treasure_hunt.exe" file.
2. Enter your directional movement commands into the prompt to move your character around the board. (w,a,s,d)
3. Plan your path carefully to navigate around the `x` wall boundaries and move through `.` spaces until you reach the `T` treasure!
